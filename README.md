# contato-abrigos-recife
Sistema de rede apoio para localizar animais em situação de rua e direcioná-los para abrigos disponíveis

## necessidades:
    ter contato e loc de abrigos de animais e veterinários na cidade do recife
    app com mapa interativo - marcadores de localização do usuário, marcadores de localização de alertas, marcadores de localização de abrigos, marcadores de localização de veterinários
    app para cidadãos criarem alerta/notificação no app (com comprovação fotográfica) de animal em situação de rua
    app guiar usuário para abrigo mais próximo (caso o usuário decida ele mesmo levar o animal) 
    app guiar usuário para veterinário mais próximo (caso o usuário decida ele mesmo levar o animal) 

    essas são as implementações que consideramos básicas para o funcionamento do nosso produto
